### 1.3 User — 用户

```python
# apps/system/models/user.py

class UserModel(SQLModel, table=True):
    __tablename__ = "user"
    id: int
    account: str          # 登录账号
    name: str             # 显示名称
    password: str         # 密码（bcrypt 加密）
    oid: int              # 默认工作空间 ID
    status: int           # 状态：1=启用, 0=禁用
    language: str         # 语言偏好（zh/en/ko）
    create_time: datetime
```

### 1.4 Workspace — 工作空间

工作空间是**数据隔离**的基本单位：

```python
class WorkspaceModel(SQLModel, table=True):
    __tablename__ = "workspace"
    id: int
    name: str             # 工作空间名称
    description: str
    create_time: datetime
```

- 每个数据源、对话、术语表都属于一个工作空间
- 用户通过工作空间访问资源
- 一个用户可以属于多个工作空间

### 1.5 Assistant — 助手（嵌入式问答）

助手是 SQLBot 提供给外部系统集成的能力：

```python
class AssistantModel(SQLModel, table=True):
    __tablename__ = "assistant"
    id: int
    name: str             # 助手名称
    type: int             # 类型：
                          #   0=标准助手（绑定固定数据源）
                          #   1=动态助手（动态数据源）
                          #   3=API 数据源助手
                          #   4=页面嵌入式助手
    oid: int              # 所属工作空间
    domain: str           # 允许的域名（CORS）
    app_secret: str       # 嵌入式认证密钥
    custom_model: int     # 指定的 AI 模型 ID
```

**助手的认证方式**：
```
# 标准助手认证
X-SQLBOT-ASSISTANT-TOKEN: Assistant <JWT>

# 嵌入式认证（网页嵌入）
X-SQLBOT-ASSISTANT-TOKEN: Embedded <JWT>
```

### 1.6 登录流程

```python
# apps/system/api/login.py

@router.post("/login")
async def login_access_token(session, user_in: Login):
    # 1. 查找用户
    user = get_user_by_account(session, account=user_in.account)

    # 2. 验证密码（bcrypt）
    if not security.verify_password(user_in.password, user.password):
        raise HTTPException(status_code=401, detail="密码错误")

    # 3. 检查用户状态
    if user.status != 1:
        raise HTTPException(status_code=401, detail="用户已禁用")

    # 4. 生成 JWT Token
    access_token_expires = timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    token = security.create_access_token(user.id, expires_delta=access_token_expires)

    # 5. 返回 Token
    return {"token": token, "user": user}
```

### 1.7 权限控制

使用 `@require_permissions` 装饰器控制接口权限：

```python
@router.post("/start")
@require_permissions(permission=SqlbotPermission(type='ds', keyExpression="create_chat_obj.datasource"))
async def start_chat(session, current_user, create_chat_obj):
    ...
```

- `type='ds'` → 检查数据源级别的权限
- `keyExpression` → 从请求参数中提取数据源 ID
- 普通用户只能访问有权限的数据源和对话

### 1.8 系统参数

```python
# 系统参数允许管理员动态配置系统行为
class SysArgModel(SQLModel, table=True):
    __tablename__ = "sys_arg"
    pkey: str    # 参数键（如 "chat.limit_rows"）
    pval: str    # 参数值（如 "500"）

```

已使用的系统参数：
| 参数键 | 功能 | 默认值 |
|--------|------|--------|
| `chat.sqlbot_name` | AI 助手名称 | SQLBot |
| `chat.limit_rows` | 是否启用 SQL 行数限制 | true |
| `chat.context_record_count` | 保留的历史对话轮数 | 3 |

## 2. 术语表模块 (`apps/terminology/`)

### 2.1 功能

术语表让 LLM 理解业务术语的含义，提高 SQL 生成的准确性。

```python
class Terminology(SQLModel, table=True):
    __tablename__ = "terminology"
    id: int
    term: str            # 术语名称（如 "ROI"）
    description: str     # 描述（如 "投资回报率"）
    synonym: str         # 同义词（如 "回报率,利润率"）
    oid: int             # 所属工作空间
    ds_id: int           # 所属数据源（可选，NULL=工作空间级）
    embedding: str       # 向量嵌入
```

### 2.2 使用方式

1. 管理员在后台配置术语表
2. 用户提问时，系统通过 Embedding 匹配相关术语
3. 匹配到的术语注入到 Prompt 中
4. LLM 根据术语定义生成更准确的 SQL

## 3. 数据训练模块 (`apps/data_training/`)

### 3.1 功能

数据训练 = SQL 示例库。管理员配置"问题 → SQL"的示例，帮助 LLM 学习特定场景的 SQL 写法。

```python
class DataTraining(SQLModel, table=True):
    __tablename__ = "data_training"
    id: int
    question: str        # 问题示例（如 "各区域上月销售额"）
    sql: str             # 对应的 SQL（如 "SELECT region, SUM(amount) FROM sales WHERE..."）
    description: str     # 描述
    oid: int             # 所属工作空间
    ds_id: int           # 所属数据源（可选）
    embedding: str       # 向量嵌入（基于 question）
```

### 3.2 使用方式

与术语表类似：
1. 用户提问 → Embedding 匹配 → 找到相似的 SQL 示例
2. 示例注入到 Prompt 的 `<m-data-training>` 部分
3. LLM 参考示例生成 SQL

## 小结

1. **系统管理**：用户/工作空间/助手/AI模型/API Key 的管理和认证
2. **工作空间**：数据隔离的基本单位，所有资源都归属于某个工作空间
3. **助手**：提供嵌入式问答能力，支持多种类型（标准/动态/API/页面嵌入）
4. **术语表**：业务术语定义，通过 Embedding 匹配注入到 Prompt
5. **数据训练**：SQL 示例库，帮助 LLM 学习特定场景
6. **审计日志**：记录用户操作，支持追溯
7. **MCP**：标准协议接口，供外部 AI Agent 调用
