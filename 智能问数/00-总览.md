## 🎯 一句话了解 SQLBot

**SQLBot 是一个基于大语言模型（LLM）的智能数据问答平台**：用户用自然语言提问，系统自动生成 SQL、查询数据库、生成图表，支持多种数据库和多种 AI 模型。

## 🔄 核心请求流程（最重要的一个流程）

用户提一个问题的完整链路：

```
用户提问: "上个月各部门的销售额是多少？"
    │
    ▼
[1] chat/api/chat.py → 接收 POST /api/v1/chat/question
    │
    ▼
[2] chat/task/llm.py → LLMService.run_task()
    │
    ├─→ [2.1] 选择数据源（如果没有指定）
    │         通过 Embedding 语义匹配最相关的数据库
    │
    ├─→ [2.2] 获取表结构（choose_table_schema）
    │         从数据库获取相关表和字段信息
    │
    ├─→ [2.3] 过滤术语表 + SQL示例 + 自定义Prompt
    │         用 Embedding 匹配相关术语和示例
    │
    ├─→ [2.4] 构建 Prompt → 调用 LLM 生成 SQL
    │         将表结构、术语、示例组装成提示词
    │         → LLM 返回: SELECT dept, SUM(amount) FROM sales WHERE ...
    │
    ├─→ [2.5] 安全检查 + 权限过滤
    │         检查 SQL 是否有写操作、危险函数
    │         根据用户权限添加行级过滤条件
    │
    ├─→ [2.6] 执行 SQL → 获取查询结果
    │         连接用户数据源执行 SQL
    │
    └─→ [2.7] 调用 LLM 生成图表配置
              根据 SQL 结果生成图表类型、轴配置等
              → 返回前端渲染图表
```

## 🐍 Python 基础速查（给零基础同学）

在阅读后续文档前，了解以下 Python 概念会帮助你更快上手：

| 概念 | 在本项目中的体现 | 一句话解释 |
|------|----------------|-----------|
| **装饰器 `@`** | `@router.get(...)`, `@system_log(...)` | 像"包装纸"一样给函数添加额外功能 |
| **类 `class`** | `LLMService`, `CoreDatasource` | 对象的蓝图，把数据和方法组织在一起 |
| **异步 `async/await`** | `async def question_answer(...)` | 不阻塞的请求处理，适合 I/O 密集型应用 |
| **类型注解 `:`** | `session: SessionDep`, `-> str` | 标注变量/返回值类型，提高代码可读性 |
| **Pydantic Model** | `ChatQuestion`, `DatasourceConf` | 数据验证工具，自动校验输入数据格式 |
| **SQLModel** | `CoreDatasource`, `ChatRecord` | = SQLAlchemy + Pydantic，同时做 ORM 和数据验证 |
| **生成器 `yield`** | `LLMService.run_task()` 中的流式输出 | 一个可以"暂停"和"恢复"的函数，用于流式返回数据 |
| **字典/列表推导** | `{k: v for ...}`, `[x for x in ...]` | 快速构建字典/列表的简洁语法 |
| **`with` 语句** | `with Session(engine) as session:` | 自动管理资源（如数据库连接）的开关 |
| **f-string** | `f"Hello {name}"` | 字符串模板，在 `{}` 中直接嵌入变量 |
