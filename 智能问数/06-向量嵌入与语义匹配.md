## 1. 什么是向量嵌入（Embedding）

**一句话解释**：把文本转换成一个数字向量（如 `[0.12, -0.34, 0.56, ...]`），语义相似的文本，向量距离更近。

```
"上个月销售额"  →  [0.12, -0.34, 0.56, ...]
"上月营收"      →  [0.11, -0.33, 0.55, ...]  ← 语义相似，向量接近
"天气预报"      →  [-0.89, 0.67, -0.12, ...] ← 语义不同，向量远离
```

在 SQLBot 中，Embedding 用于以下场景：

| 场景 | 输入 | 输出 |
|------|------|------|
| 术语匹配 | 用户问题 | 匹配相关的业务术语定义 |
| SQL 示例匹配 | 用户问题 | 匹配相似的历史 SQL 示例 |
| 数据源匹配 | 用户问题 | 匹配最可能用到的数据库 |
| 表匹配 | 用户问题 | 匹配最相关的数据库表 |

## 3. 余弦相似度计算

两个向量的相似度通过**余弦相似度**衡量：

```python
# apps/datasource/embedding/utils.py

def cosine_similarity(vec1, vec2):
    """计算两个向量的余弦相似度"""
    # cos(θ) = (A·B) / (|A| × |B|)
    # 值域：[-1, 1]，越接近 1 越相似
    dot_product = sum(a * b for a, b in zip(vec1, vec2))
    magnitude1 = math.sqrt(sum(a * a for a in vec1))
    magnitude2 = math.sqrt(sum(b * b for b in vec2))
    return dot_product / (magnitude1 * magnitude2)
```

```
相似度 = 1.0  → 完全相同
相似度 = 0.8  → 非常相似
相似度 = 0.4  → 有一定相关性（阈值）
相似度 = 0.0  → 完全不相关
```

## 4. 术语表匹配

### 4.1 术语表数据

```python
class Terminology(SQLModel, table=True):
    __tablename__ = "terminology"
    id: int
    term: str           # 术语名称（如 "ROI"）
    description: str    # 术语描述（如 "投资回报率 = 净利润 / 投资额 × 100%"）
    synonym: str        # 同义词（如 "回报率,投资回报率"）
    oid: int            # 所属工作空间
    embedding: str      # 向量嵌入（描述 + 同义词的向量）
```

### 4.2 匹配流程

```python
# apps/terminology/curd/terminology.py

def get_terminology_template(session, question, oid, ds_id=None, assistant_id=None):
    """根据用户问题匹配相关术语"""

    # 1. 查询该工作空间的所有术语
    stmt = select(Terminology).where(Terminology.oid == oid)
    terminologies = session.exec(stmt).all()

    # 2. 将用户问题转为向量
    model = EmbeddingModelCache.get_model()
    question_embedding = model.embed_query(question)

    # 3. 计算问题与每个术语的相似度
    results = []
    for term in terminologies:
        if term.embedding:
            term_embedding = json.loads(term.embedding)
            similarity = cosine_similarity(question_embedding, term_embedding)

            if similarity >= settings.EMBEDDING_TERMINOLOGY_SIMILARITY:  # >= 0.4
                results.append({
                    'term': term,
                    'similarity': similarity
                })

    # 4. 按相似度排序，取 Top N
    results.sort(key=lambda x: x['similarity'], reverse=True)
    results = results[:settings.EMBEDDING_TERMINOLOGY_TOP_COUNT]  # Top 5

    # 5. 构建术语表文本，注入到 Prompt
    template = "\n".join([
        f"- {r['term'].term}: {r['term'].description}"
        for r in results
    ])
    return template, results
```

### 4.3 示例

```
用户问题: "上个月各产品线的 ROI 是多少？"

匹配到的术语:
  - ROI: 投资回报率 = 净利润 / 投资额 × 100%（相似度: 0.92）
  - 产品线: 业务部门划分的独立产品单元（相似度: 0.67）
  - 净利润: 总收入减去总成本后的金额（相似度: 0.45）

注入到 Prompt:
```

## 5. 数据源匹配

当用户没有指定数据源时，系统通过 Embedding 匹配最相关的数据库：

```python
# apps/datasource/embedding/ds_embedding.py

def get_ds_embedding(session, ds_list, out_ds, question, current_assistant):
    """根据问题匹配最相关的数据源"""

    # 1. 构建每个数据源的描述文本
    _list = []
    for ds_info in ds_list:
        ds = session.get(CoreDatasource, ds_info['id'])
        table_schema, tables = get_table_schema(ds, question, embedding=False)
        ds_text = f"{ds.name}, {ds.description}\n{table_schema}"
        _list.append({
            "id": ds.id,
            "ds_schema": ds_text,
            "cosine_similarity": 0.0
        })

    # 2. 批量计算向量
    model = EmbeddingModelCache.get_model()
    text_embeddings = model.embed_documents([item['ds_schema'] for item in _list])
    question_embedding = model.embed_query(question)

    # 3. 计算相似度
    for i, embedding in enumerate(text_embeddings):
        _list[i]['cosine_similarity'] = cosine_similarity(question_embedding, embedding)

    # 4. 排序 + 取 Top N
    _list.sort(key=lambda x: x['cosine_similarity'], reverse=True)
    _list = _list[:settings.DS_EMBEDDING_COUNT]  # Top 10

    return [{"id": obj['id'], "name": ..., "description": ...} for obj in _list]
```

```python
# common/utils/embedding_threads.py

def fill_empty_terminology_embeddings():
    """查找所有 embedding 为空的术语，计算并保存"""
    model = EmbeddingModelCache.get_model()
    terms = session.exec(
        select(Terminology).where(Terminology.embedding.is_(None))
    ).all()
    for term in terms:
        text = f"{term.term} {term.synonym} {term.description}"
        embedding = model.embed_query(text)
        term.embedding = json.dumps(embedding)
        session.add(term)
    session.commit()
```

## 小结

1. **Embedding 模型**：默认使用 `text2vec-base-chinese`，将文本转为向量
2. **余弦相似度**：衡量两个向量的相似程度，阈值默认 0.4
3. **四种匹配场景**：术语表、SQL 示例、数据源、表结构
4. **Top N 筛选**：每种匹配取相似度最高的 N 个结果
5. **后台初始化**：启动时自动为缺少向量的数据计算 Embedding
6. **向量存储**：存储在 PostgreSQL 的 Text 字段中（JSON 格式）
